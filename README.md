# Nyati Crypto Exchange

Fast, secure, and affordable cryptocurrency exchange platform operating in Africa.

## Technologies Used

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase

## Getting Started

### Prerequisites

Ensure you have Node.js (v18+) and npm or bun installed.

### Installation

```sh
# Install dependencies
npm install

# Start development server
npm run dev
```

### Building for Production

```sh
npm run build
```
